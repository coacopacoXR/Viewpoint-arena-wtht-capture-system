## [Unreleased]

### Added

- Initial project scaffolding with Vite + React + TypeScript.
- 3D scene rendering with Three.js (`@react-three/fiber`, `@react-three/drei`).
- Viewpoint mode system (Manager, Operator, Review).
- Insight deck with card-based capture output.
- Model import support (GLB, glTF, OBJ, FBX, STL).
- WebRTC peer connection with Cloudflare Realtime TURN integration.
- PartyKit-based real-time collaboration.
- SharePoint and Microsoft Teams notification integrations.
- Onshape and Teamcenter PLM connector adapters.
- Apache-2.0 license and OSS baseline files (CONTRIBUTING.md, CODE_OF_CONDUCT.md, SECURITY.md, CHANGELOG.md).
